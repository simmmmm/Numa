# Security

## Report a vulnerability

Do not open a public issue.

1. Go to the Security tab of this repository.
2. Select **Report a vulnerability**.
3. Write what you found and how to do it again.

You get an answer in 7 days. One person makes Numa, so a fix can take more time.

## Which versions get fixes

Only the newest release gets fixes.

## What to look at first

Numa operates on your computer. Numa Home operates on your server and accepts
connections. Thus Numa Home has the highest risk: its accounts, share links,
uploads and archives.
